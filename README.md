# Море мудрости — карта

Радиальная интерактивная карта по тексту «Море мудрости» (объяснение «Мудрости» Арьи Нагарджуны; автор — Чже Цонгкапа).
Версия документа: **17.08.26**.

## Что здесь

- `index.html` — сама карта; картинки встроены как data-URI, ничего внешнего не подгружает.
- `more-mudrosti-original.pdf` — оригинал PDF (кнопка «Открыть оригинал PDF» ведёт сюда).
- `.nojekyll` — отключает Jekyll (нужно для статики на GitHub Pages).

## Как обновить сайт

Через веб-интерфейс GitHub (без терминала):
1. Открыть `https://github.com/Rone1313/Nagarjuna`
2. `Add file` → `Upload files` (или прямая ссылка `https://github.com/Rone1313/Nagarjuna/upload/main`).
3. Перетащить мышкой файлы `index.html`, `more-mudrosti-original.pdf`, `README.md` (не папку).
4. `Commit changes` (ветка `main`).
5. Через 1–2 минуты открыть `https://rone1313.github.io/Nagarjuna/` и нажать **Cmd+Shift+R** / **Ctrl+Shift+R**.

Вход: пароль `nagarjuna2026` (можно поменять в `gen_map2.py` → `PASSWORD` и пересобрать).
